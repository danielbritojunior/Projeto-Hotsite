# 🚗 Carro por Assinatura | Landing Page Premium

## ✨ Visão Geral do Projeto
Este projeto é uma **Landing Page completa e responsiva**, desenvolvida para simular uma plataforma moderna de assinatura de carros 0km.  
O objetivo principal é servir como um projeto de portfólio de alto nível, demonstrando **proficiência em design, responsividade e lógica front-end**, com foco em **conversão e experiência do usuário (UX)**.

---

## 🎯 Destaques e Funcionalidades
O site combina **estética com funcionalidade**, garantindo uma navegação intuitiva em qualquer dispositivo.

- **Design e UX Responsivo:** Layout fluido e adaptável para desktop, tablet e mobile.
- **Identidade Visual Elegante:** Tipografia Poppins e cores vibrantes em gradientes de laranja e vermelho.
- **Navegação Acessível:** Menu fixo (sticky) com **Menu Hambúrguer** animado para dispositivos móveis.
- **Ícones Profissionais:** Uso de Font Awesome para complementar a interface.
- **Formulário Inteligente:** Validação robusta (client-side) para:
  - Nome completo (exige pelo menos dois nomes e sem números)
  - E-mail (formato Regex)
  - WhatsApp (formatação automática e 11 dígitos)
  - Modelo de interesse (seleção obrigatória)

---

## 📑 Estrutura de Conteúdo
O site é dividido em seções estratégicas para conversão:

1. **Hero:** Chamada principal
2. **Frota de Veículos**
3. **Vantagens do Serviço**
4. **Passo a Passo (Como Funciona)**
